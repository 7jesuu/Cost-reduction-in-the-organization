# Ключевой слой — Hardware Abstraction Layer (HAL) / Device Gateway, который работает на Edge (на планшете или небольшом edge-устройстве рядом с кассой).

## Кассовое приложение (Web POS / тонкий клиент) общается только с HAL по единому локальному API (например, REST/gRPC на localhost или WebSocket).
- HAL содержит адаптеры (плагины) под каждый тип терминала и фискальника:
- Сбер ARCUS-2
- Альфа
- Ingenico
- Verifone
- Разные модели фискальных регистраторов

При появлении нового терминала пишется только новый адаптер в HAL. Кассовый софт и облако не переписываются.
Payment Gateway в облаке отвечает за бизнес-логику платежей (возвраты, частичные оплаты, лояльность), а HAL — только за физическое взаимодействие с устройством.

Таким образом, жёсткая связка «касса ↔ драйвер» полностью разрывается.


# Механизм работы без интернета:

1) Local Cache + Offline Queue
На Edge постоянно хранится актуальный снимок критичных данных: номенклатура, цены, остатки (с ограничением по времени/объёму), правила лояльности. Все операции (продажа, возврат, применение баллов) записываются в локальную очередь с уникальным transaction_id и статусом pending.

2) Фискализация всегда локальная
Фискальный регистратор управляется через HAL. Чек печатается и фискализируется даже при полном отсутствии связи. Это обязательное требование законодательства.

3) Синхронизация при восстановлении связи
Когда интернет появляется, Edge Agent:
- Отправляет все накопленные транзакции в Cloud POS Service в порядке их создания (с идемпотентностью по transaction_id).
- Получает подтверждение и помечает их как synced.
- Запрашивает дельту изменений каталога, цен и лояльности (last-sync-timestamp).
- Обновляет локальный кэш.
- При конфликтах (например, товар уже продан в другом магазине) применяется политика «cloud wins» + уведомление Store Ops.

4) Ограничения offline-режима
- Карты лояльности работают только в рамках закэшированных правил (без онлайн-проверки баланса).
- Недоступны операции, требующие real-time подтверждения банка (некоторые виды безнала). Наличные + фискальный чек — всегда доступны.

# Результат для бизнеса:
- Локальные серверы и Windows/SQL-лицензии полностью убираются → снижение TCO ≥ 40 %.
- Подключение нового магазина сокращается до 3–5 дней (выгрузка + AI-маппинг + установка планшета + HAL-адаптеры).
- Любой новый банковский терминал подключается через добавление адаптера, без пересборки кассового приложения.
